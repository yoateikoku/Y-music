# Y-music
Y-Music by yoateikoku — A single-deck DJ music player and Hi-Fi audio studio built with pure HTML, CSS, and Vanilla JavaScript. Features smart URL extraction, Audius/iTunes search, Web Audio API Hi-Fi DSP, rainbow spectrum visualizer, NON-STOP playback, persistent playlists, WAV export, and live DJ recording.
